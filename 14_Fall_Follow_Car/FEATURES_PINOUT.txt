【一、軟體功能】
1. 視覺跟隨（YOLO-pose + ByteTrack）
2. UWB 距離跟隨
3. 特定人鎖定 + HSV Re-ID
4. 跌倒偵測 + LINE + 急停 X
5. 正前避障：1×VL53；F 且 <250mm → S
6. 網頁 :5001（UWB + 正前 ToF）

【二、供電】
邏輯：3S → DC → XY3606(~5.1V) → USB-C → Pi5 → USB 供相機/ESP32/UNO
馬達：獨立電池 → BMP73T104（跳帽勿灌 UNO）
共地：兩電池負極短接

【三、協定】
Pi ← ESP32：D:x.xx 、 O:mm（正前）
Pi → ESP32 → UNO：F/L/R/Z/S/X
ESP32 GPIO17 → UNO D10；UNO D11 → ESP32 GPIO16

【四、腳位】
UNO D10 ← 命令；D11 → O:
VL53 正前：VCC=5V GND SDA=A4 SCL=A5 XSHUT=D3（0x29）
※ 不要接 D2/D4/D5 其他 VL53

【五、燒錄】
UNO：firmware/uno_car/uno_car.ino
ESP32：firmware/uwb_car_responder/uwb_car_responder.ino
Tag：uwb_tag_initiator（沿用）
Pi：fall_follow_car.py + line_media.py
