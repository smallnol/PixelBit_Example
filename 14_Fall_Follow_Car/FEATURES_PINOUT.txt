【一、目前軟體功能】
--------------------------------------------------------------------------------
1. 視覺跟隨
   - USB 相機 + YOLOv8n-pose + ByteTrack
   - 鎖定目標後：左偏→L、右偏→R、沒人→Z；置中後看 UWB 距離決定 F／S

2. UWB 距離跟隨
   - 身上 Tag ↔ 車載 ESP32 DS-TWR
   - 預設：≥2.0 m 前進、＜1.8 m 停下；距離逾時（約 1s）不前進

3. 特定人鎖定
   - 網頁「鎖定畫面中央」或舉手約 2 秒
   - HSV Re-ID：遮擋／換 track ID 時嘗試綁回同一人
   - 跟隨與跌倒只分析鎖定目標；路人 IGNORED

4. 跌倒偵測 + LINE 通報
   - 姿態疑似約滿 10 秒才確認
   - 確認後：LINE 文字＋照片＋影片；馬達 X 急停；可自動關跟隨
   - 桌前坐姿排除；短暫蹲下站起自清

5. 底層避障（4×VL53，UNO 執行）
   - 左前／正前／右前：前進 F 時過近（＜250mm）→ 停或微偏
   - 正後：自轉 Z 時過近 → 強制停
   - X 最高優先，不被避障覆寫

6. 網頁儀表板（:5001）
   - 跟隨／跌倒開關、鎖定、手動遙控（跟隨 ON 時方向鍵互鎖）
   - UWB／ToF 即時數值、跌倒警報橫幅、MJPEG 預覽


【二、供電（目前文件）】
--------------------------------------------------------------------------------
【邏輯電｜電池 A】
  3S 18650（約 11.1V）
    → DC 頭
    → XY3606 降壓（請調約 5.1V）
    → USB
    → Type-C
    → 樹莓派 5
    → Pi USB 口再供：USB 相機、車載 ESP32-UWB、Arduino UNO

【馬達電｜電池 B】
  獨立電池（3S／4S 依 BMP73T104）
    → 只接 BMP73T104 馬達 VIN／馬達電
    → 跳線帽勿把高壓灌進 UNO 5V

【共地】
  電池 A 負極 ──短接── 電池 B 負極（單點）
  正極絕對不要併聯


【三、通訊與協定】
--------------------------------------------------------------------------------
Pi USB (/dev/ttyUSB0, 115200) ↔ 車載 ESP32
  Pi ← ESP32：D:x.xx（UWB 公尺）、O:a,b,c,d（ToF mm）
  Pi → ESP32：F / L / R / Z / S / X + 換行

車載 ESP32 ↔ UNO（SoftSerial 9600）
  ESP32 GPIO17 → UNO D10 ：馬達命令
  UNO D11 → ESP32 GPIO16 ：O: 回傳
  GND 共地

馬達命令語意：F前進 L左 R右 Z搜尋自轉 S停 X緊急煞停


【四、元件腳位表】
--------------------------------------------------------------------------------

────────────────────────────────────────
A. 樹莓派 5
────────────────────────────────────────
  USB Type-C 電源入 ← XY3606 輸出（約 5.1V）
  USB-A ← 車載 ESP32-UWB（通訊＋供電）
  USB-A ← Arduino UNO（供電；通訊走 ESP32 轉發，UNO 可不佔第二通訊口）
  USB-A ← USB 廣角攝影機
  （不接 Pi GPIO 當馬達 UART；勿用 serial0/ttyAMA0 當馬達口）

────────────────────────────────────────
B. 車載 ESP32-UWB（Responder + 橋接）
────────────────────────────────────────
  USB          → 樹莓派 USB（D:/O: 上傳；收馬達命令）
  GPIO17 (TX2) → UNO D10
  GPIO16 (RX2) ← UNO D11
  GND          ↔ UNO GND
  DW3000 板載腳（韌體常數，通常板載已接好）：
    RST = GPIO27
    IRQ = GPIO34
    SS  = GPIO4
    （SPI 其餘腳依模組／庫預設）

────────────────────────────────────────
C. 身上 Tag ESP32-UWB（Initiator）
────────────────────────────────────────
  獨立供電開機即可；與車載以 UWB 無線測距（無實體訊號線到車）
  DW3000 腳位同生態專案 uwb_tag_initiator

────────────────────────────────────────
D. Arduino UNO + BMP73T104
────────────────────────────────────────
  D10  ← ESP32 GPIO17（SoftSerial RX，命令）
  D11  → ESP32 GPIO16（SoftSerial TX，O:）
  5V   → 四顆 VL53 VCC（建議；Pololu 等模組可吃 5V）
  GND  ↔ ESP32 GND、VL53 GND、與馬達電池負極共地
  SDA  ↔ 四顆 VL53 SDA（UNO A4）
  SCL  ↔ 四顆 VL53 SCL（UNO A5）
  BMP73T104 插在 UNO 擴充座：
    馬達通道 M1=左後、M2=右後、M3=右前、M4=左前（程式註解）
    馬達電來自電池 B（勿灌 UNO 5V）

────────────────────────────────────────
E. 4× VL53L0X（共用 SDA/SCL/VCC/GND）
────────────────────────────────────────
  方位     XSHUT(UNO)   I2C 位址    行為
  左前     D2           0x30        前進避障
  正前     D3           0x31        前進避障
  右前     D4           0x32        前進避障
  正後     D5           0x33        自轉 Z 過近則停

  遙測：O:左前,正前,右前,正後
  門檻：AVOID_MM=250（過近）
  ※ 已移除「前端下視防墜」；不再使用 D6／CLIFF_MM

────────────────────────────────────────
F. USB 廣角攝影機
────────────────────────────────────────
  USB → 樹莓派；軟體 CAMERA_INDEX 預設 0
